Working on this multi-agent workflow taught me a lot about how fragile and powerful agent coordination can be. Before doing this assignment, I thought “Planner” and “Reviewer” sounded like a simple split. Once I actually implemented them, I realized how much their behavior depends on the exact wording of their instructions. When the roles were clear, the whole system felt smooth and intentional. When they weren’t, things fell apart quickly.

I also ran into several issues that forced me to rethink my prompt design. At the start, my Reviewer agent kept flagging the accommodation as too expensive and then deleted all the hotels from the itinerary. It technically followed my instructions, but the result was completely unrealistic. I had to rewrite the Reviewer instructions to make it suggest cheaper alternatives instead of wiping things out. Another problem was that it only output the revised days instead of the full itinerary. This broke the flow of the app because the user needed one clean, final plan. Updating the prompt so the Reviewer always rewrites the entire trip fixed that behavior.

I also noticed that the Reviewer sometimes forgot to include accommodation, breakfast, lunch, and dinner for some days. That made me realize how literal these agents are. If something isn’t explicitly required, they won’t consistently do it, even if it seems obvious. Adding clear, explicit instructions for daily meals and lodging made the output much more stable.

I ended up experimenting with the tone and structure of the prompts to make the Reviewer more constructive and consistent. The process taught me that designing multi-agent systems is really about designing communication. Tiny changes in phrasing can completely change the outcome, and getting the two agents to work together felt almost like guiding two different personalities toward the same goal.


AI usage:
For external tools, I did use AI to help refine some of my prompt wording. I wrote out the specific requirements and behaviors I wanted from the Planner and Reviewer, then asked AI to help me rephrase those instructions so they were clearer, more structured, and easier for another agent to interpret. My goal wasn’t to have it generate the logic for me, but to make sure the language I used was unambiguous and aligned with how LLM agents typically understand tasks. This was especially helpful when I needed the Reviewer to stop deleting accommodations, to always output the full revised itinerary, and to consistently include meals and lodging each day. Using AI this way felt more like using an editor or writing assistant to refine the instructions rather than outsourcing the actual work.
