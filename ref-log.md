# External Tools and GenAI Usage Log

### External Libraries
- **Streamlit** – UI and chat interface.  
- **OpenAI SDK** – Model and embedding API calls.  
- **LangChain + Chroma** – RAG and vector retrieval.  
- **PyPDF** – PDF text extraction.  
- **tiktoken** – Token counting for chunking.  

### Environment Variables
`OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`, `RAG_CHUNK_SIZE`, `RAG_CHUNK_OVERLAP`, `RAG_TOP_K`.

GenAI tools were used to clarify code functionality, adapt existing RAG methods, and produce concise technical documentation.
